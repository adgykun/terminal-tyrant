# Terminal Tyrant / 终端霸主

纯前端 React 18 + TypeScript + Vite 文字 RPG（无后端）。文字大地图、攻城、市场、酒馆、竞技场、佣兵/骑士团、老虎机赌博，以及 12 个可程序化生成的区域。

## 在线试玩

**[▶ 点击这里直接玩](https://adgykun.github.io/terminal-tyrant/)**

> 站点由 GitHub Pages 自动部署（源码 push 到 main 即自动构建上线）。

## 本地运行

```bash
npm install
npm run dev      # 本地开发
npm run build    # 构建
```

## 特性

- 大地图自由移动（Canvas 渲染 + 骑砍式路径移动）
- 城镇：市场买卖、兵营招募、酒馆/竞技场、老虎机
- 战斗、佣兵/骑士团、12 个程序化区域
- 响应式，移动端可玩
